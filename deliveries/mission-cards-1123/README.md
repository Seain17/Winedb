# 미션 모으기 카드 전용 리소스 · 11-23

3차 요청에 따라 동작이 다른 카드 그림 3장만 추가합니다. 1·2차의 기존 파일은 변경하지 않았습니다.

| 파일 | 동작 | 스카프 |
|---|---|---|
| `cards/card_exact-change.png` | 하늘다람쥐가 점프하며 동전을 튕김 | 하늘색 |
| `cards/card_smishing-catch.png` | 레서판다가 앞으로 숙여 돋보기로 휴대폰 조사 | 노랑 |
| `cards/card_smart-shopping.png` | 아기판다가 카트를 밀며 오른쪽으로 달림 | 주황 |

모두 1024×1024 RGBA 투명 PNG입니다. 카드 바탕색은 이미지에 포함하지 않았습니다. 긴 쪽 채움 80~88%, 아래 여백 5~8%, 나머지 여백 6% 이상을 실측했고, 136px 카드와 48px 썸네일에서 동작을 확인했습니다. 아래 여백은 모두 68px입니다. 정확한 경계·채움·여백·SHA-256은 `verification.txt`에 기록했습니다.

ZIP에는 PNG 3장과 이 문서, `verification.txt`가 들어 있습니다. 문서 2개는 ZIP 밖에도 동일하게 제공합니다.
