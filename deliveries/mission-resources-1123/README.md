# 미션 모으기 추가 리소스 · 11-23

11-23 요청서에서 추가되거나 수정된 5장만 포함합니다. 11-17의 기존 24장과 지폐는 변경하지 않았습니다.

| 파일 | 크기 | 변경 내용 |
|---|---|---|
| `gate/gate_hero.png` | 1536×1024 | 하늘다람쥐·레서판다·아기판다 게이트 그림 추가 |
| `gate/stamp_sheet.png` | 1024×512 | 찍힘·빈칸 스탬프 2칸 추가 |
| `gate/reward_sheet.png` | 1024×512 | 닫힘·열림 보상 상자 2칸 추가 |
| `change/coins_sheet_v2.png` | 1536×1024 | 동전 3칸, 지름 400·360·320px, 투명 여백 확보 |
| `shopping/banner_art_v2.png` | 1536×1024 | 선택 항목 포함: 우유·사과·빈 가격표 바구니, 오른쪽 25% 비움 |

모든 이미지는 실제 알파가 있는 RGBA PNG입니다. 장보기 배너는 요청서 내 배경 지시가 상충하여 공통 규칙을 우선했고, 빈 공간을 투명하게 두었습니다. 연보라 배경은 화면 코드에서 적용할 수 있습니다.

`atlas-map.json`에는 원본 전체 크기, 각 칸의 자르기 좌표, 실제 알파 영역을 기록했습니다. 좌표 원점은 왼쪽 위이며 단위는 px입니다. `gate_hero.png`의 권장 3:1 자르기 영역은 x=0, y=256, width=1536, height=512입니다. 동전은 각 512×1024 칸을 같은 배율로 처리하면 100:90:80 비율이 유지됩니다.

`verification.txt`는 실제 파일의 크기·알파·여백·지름 검사 결과와 SHA-256을 포함합니다. 위 PNG 5장과 이 문서, 좌표표, 검수 기록을 ZIP 안에 넣었으며 문서 3개는 ZIP 밖에도 동일하게 제공합니다. 앱 연결·압축·빌드 검사는 요청서에 따라 수신 측에서 진행합니다.
