## 상태·교체 규칙

- `S-LOCKED2`: 왼쪽부터 A1 레서판다 → A2 카피바라 → A3 양 → A4 하늘다람쥐 → A5 판다. 연회색 `#C6C7C9` 단색, 표정·무늬 없음. 가장자리의 알파만 안티앨리어싱합니다.
- 마이 탭은 선택·미선택을 별도 그림으로 제공합니다. 미선택은 불투명도를 낮춘 이미지가 아니라 차분한 회갈색 배색입니다.
- `I-CHARGE`와 `B-CHARGE`: 체크리스트와 은색 클로버 코인으로 교체했으며 번개가 없습니다. 배너 왼쪽 666px(최소 62%)은 완전히 투명한 텍스트 자리입니다.
- `UI-OW-PENDING`: 왼쪽 0번 → 오른쪽 1번, 600ms씩 반복 권장. 모래시계와 코인 위치는 고정, 모래 분포만 바뀝니다.
- `UI-FLOAT-CLOSE`: 0번 기본 / 1번 닿음. 자동 반복 애니메이션이 아니라 상태에 따라 한 칸을 선택합니다.
- `UI-FLOAT-RING`: 중앙은 투명한 구멍입니다. `_full`은 같은 크기의 노란 상태입니다.
- 동물 그림은 레서판다 노랑·카피바라 초록 스카프를 유지했습니다.

## 단계 오브젝트 배치

요청서에 픽셀 크기가 없는 별도 오브젝트는 위 표의 원본 크기로 정했습니다. 같은 계열의 3단계는 캔버스·중심·바닥 기준을 고정하고, 공통 배율을 사용해 성장 차이를 보존했습니다. 각각을 내용에 맞춰 다시 잘라내거나 같은 크기로 정규화하지 마세요.

**바닥 비율은 CSS `bottom`처럼 화면 아래에서 위로 잰 값**으로 해석했습니다. 미리보기도 이 기준을 사용합니다. 원본의 공통 앵커는 `(0.5, 0.94)`입니다. 투명 여백이 있으므로 이미지 끝이 아닌 이 앵커를 지면 위치에 맞춥니다.

| 계열 | 가로 중심 | 바닥 | 캔버스 폭 |
|---|---:|---:|---:|
| S-BARN | 30% | 41% | 44% |
| S-TREE | 82% | 40% | 30% |
| S-FENCE | 50% | 43% | 100% |
| S-JOB-A1 과수원 | 32% | 57% | 24% |
| S-JOB-A2 연못 | 68% | 57% | 24% |
| S-JOB-A3 목장 | 22% | 72% | 30% |
| S-JOB-A4 숲 | 78% | 72% | 30% |
| S-JOB-A5 대나무밭 | 50% | 47% | 34% |

화면을 W×H, 표시 이미지 크기를 w×h라고 할 때:

```js
w = W * canvasWidthPercent / 100;
h = w * sourceHeight / sourceWidth;
left = W * centerXPercent / 100 - w * 0.5;
top = H * (1 - bottomPercent / 100) - h * 0.94;
```

앱이 바닥을 위쪽 원점 기준 y값으로 저장한다면 `top = H * yPercent / 100 - h * 0.94`로 적용하면 됩니다. 배경 단계와 오브젝트 단계의 레벨 매핑은 앱에서 결정합니다. 미리보기는 둘을 독립 선택하도록 구성했습니다.

## 선택 UI / 9-slice

평평한 면에 테두리·안쪽 두께선·외부 그림자를 넣지 않았습니다. 앱의 카드 테두리와 아래 그림자를 적용하세요. 버블 링과 닫기 X는 기능 자체의 도형입니다.

- `UI-GAUGE.png`: 빈 게이지 바탕. 9-slice inset `{left:20,right:20,top:19,bottom:19}`.
- `UI-GAUGE_fill.png`: 노란 그라데이션·반짝임 채움. 동일 inset. 바탕 위 별도 레이어로 놓고 진행률만큼 클립합니다. 최소 너비 40px보다 작은 구간에서는 9-slice 너비를 더 줄이기보다 클립 영역을 줄이는 것을 권장합니다.
- `UI-LV-PILL.png`: 빈 나무 명패. inset `{left:28,right:28,top:27,bottom:27}`. 레벨 문구는 앱에서 추가합니다.
- inset은 원본 픽셀 기준입니다. 크기를 줄이면 inset도 같은 비율로 줄입니다.
